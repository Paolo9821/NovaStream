# NovaStream 🎬

NovaStream is a modern, high-performance media player designed for Android devices and Android TV. It serves as a client interface for user-provided M3U and Xtream Codes playlists. **NovaStream contains no channels, streams, or media content.**

---

## 🌟 Key Features

- **Multi-Account Management**: Add multiple M3U or Xtream Codes accounts and switch between them seamlessly.
- **Smart Categorization**: Automatically categorizes content into **Live TV**, **Movies**, and **Series**.
- **Advanced Search & Filtering**: Filter content by category, release year, or group, and sort by name or recently added.
- **Playback Resume & Favorites**: Save favorite items and resume movies or series episodes right where you left off.
- **EPG Support**: Full Electronic Program Guide support via XMLTV formats provided by your service.
- **Parental Controls**: Protect specific categories using a custom PIN.
- **Built-in Diagnostics**: Integrated DNS lookup and network speed testing tools to troubleshoot playback issues.
- **Dual UI Support**: Native touch UI for smartphones/tablets and a 10-foot, remote-friendly interface for Android TV / TV boxes.
- **Robust Playback Engine**: Powered by AndroidX Media3 / ExoPlayer with HLS auto-reconnection and seamless stream recovery.

## 🚀 Quick Start & Testing

Every new installation includes a **full 7-day free trial** with access to all premium features without requiring registration or payment details.

### Demo Playlist Setup

To evaluate playback functionality and test the interface, use our royalty-free demo playlist:

1. Launch **NovaStream**, accept the terms of service, and select your device profile (**Phone/Tablet** or **Television**).
2. Go to **Accounts** > **Add Account**.
3. Select the **M3U** tab.
4. Enter the following details:
   - **Name**: `Demo`
   - **M3U URL**: `https://novastream.rork.app/demo.m3u`
5. Tap **Save**. The Live, Movies, and Series tabs will automatically populate with public test streams (including official Mux/Apple test assets and Blender open-source films).

## 🔒 Privacy & Security Architecture

NovaStream is built with a **privacy-first approach**:

| Feature | Implementation Details |
| :--- | :--- |
| **Playlist Credentials** | Encrypted locally on-device using **AES-256**. Credentials never leave your device. |
| **Advertisements** | **Zero ads**. No ad SDKs integrated (verified in application dependencies). |
| **Analytics & History** | Watch history and app logs remain strictly on the local device. |
| **Data Encryption** | All network requests to our licensing server are transmitted securely over **HTTPS**. |
| **Device Identifier** | A unique Device ID is collected solely for **license verification, app functionality, and fraud prevention**. It may be associated with purchase emails for active subscription management. |
| **Data Deletion** | Users can request data deletion at any time via [novastream.rork.app/assistenza](https://novastream.rork.app/assistenza). |
